# 채팅 웹사이트

여러 사람이 각자 기기에서 실시간으로 대화하는 채팅방입니다.

- 글 입력 후 **Enter** → 메시지 전송 (줄바꿈은 Shift+Enter)
- 📎 버튼, 드래그 앤 드롭, 이미지 붙여넣기로 파일 업로드 (최대 10MB)
- 이미지(png/jpg/gif/webp)는 채팅창에 바로 표시, html 등 나머지 파일은 다운로드 링크로만 표시
- 새로 접속하면 최근 메시지 500개를 불러옴 (`data/messages.json`에 저장)

## 실행

```bash
npm install
npm start
# http://localhost:3000
```

## 인터넷에 올리기

Node.js 서버라서 Render, Railway, Fly.io 같은 곳에 올리면 됩니다.
시작 명령은 `npm start`, 포트는 환경변수 `PORT`를 자동으로 읽습니다.

- 메시지와 업로드 파일은 `data/` 폴더에 저장됩니다. 서비스가 재시작되어도 유지하려면
  호스팅 서비스의 영구 디스크(Persistent Disk/Volume)를 연결하고 `DATA_DIR` 환경변수를 그 경로로 지정하세요.
- 이 채팅방에는 로그인이 없어서, 주소를 아는 사람은 누구나 들어올 수 있습니다.

## 보안상 해둔 것

- 메시지는 `textContent`로만 표시해서 HTML/스크립트가 실행되지 않습니다.
- 업로드된 html은 브라우저에서 열리지 않고 항상 다운로드로만 제공됩니다.
- 실행 파일(.exe, .bat 등) 업로드 차단, 파일명 무작위 저장, 도배 방지(초당 5개).
